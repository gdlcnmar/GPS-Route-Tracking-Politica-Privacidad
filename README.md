# POLÍTICA DE PRIVACIDAD
## GPS Route Tracker

**Última actualización: 30 de octubre de 2026**

### 1. Introducción

GPS Route Tracker es una aplicación diseñada para registrar, consultar y analizar recorridos mediante el sistema de posicionamiento global (GPS) del dispositivo Android.

La privacidad de los usuarios es importante. Esta política explica qué información utiliza la aplicación, cómo se almacena, para qué se utiliza y cuáles son los derechos del usuario respecto a sus datos.

Al utilizar GPS Route Tracker, el usuario acepta las prácticas descritas en esta política.

### 2. Información que recopilamos

GPS Route Tracker puede utilizar la siguiente información:

**Datos de ubicación GPS**
- Coordenadas de ubicación del dispositivo.
- Información de ubicación necesaria para registrar recorridos.
- Datos relacionados con el movimiento y las detenciones.

**Información de actividad**
- Tiempo total de movimiento.
- Tiempo de desplazamiento lento.
- Tiempo de detención.
- Fecha y duración de los recorridos.
- Información necesaria para clasificar los estados de movimiento.

**Información del dispositivo**
- Datos técnicos necesarios para el funcionamiento de la aplicación y el acceso a los servicios de ubicación de Android.

La aplicación no solicita información personal como nombre, dirección, número telefónico o contactos para realizar sus funciones principales.

### 3. Uso de la ubicación

GPS Route Tracker utiliza los servicios de ubicación de Android para registrar los desplazamientos del usuario.

La información GPS permite:
- Registrar los recorridos realizados.
- Calcular los tiempos de movimiento.
- Identificar periodos de desplazamiento lento.
- Detectar periodos de detención.
- Consultar el historial de actividad.

La aplicación puede necesitar permisos de ubicación en segundo plano para continuar registrando recorridos cuando la pantalla está apagada o cuando el usuario utiliza otras aplicaciones, siempre que esta funcionalidad esté habilitada.

El usuario puede administrar los permisos de ubicación desde la configuración de Android.

### 4. Almacenamiento de información

Los datos de los recorridos y la información de actividad se almacenan localmente en el dispositivo mediante una base de datos interna de la aplicación.

La información se utiliza para mostrar el historial de recorridos y permitir su consulta posterior.

**GPS Route Tracker no transmite los recorridos GPS a servidores externos ni comercializa la información de ubicación de los usuarios**, bajo el funcionamiento descrito en esta política.

### 5. Compartición de información

GPS Route Tracker no vende, alquila ni comparte información personal o datos de ubicación con terceros.

La información registrada se utiliza exclusivamente para proporcionar las funcionalidades de seguimiento y consulta de recorridos de la aplicación.

### 6. Conservación y eliminación de datos

Los datos de actividad permanecen almacenados en el dispositivo hasta que el usuario decide eliminarlos o desinstala la aplicación.

La aplicación permite administrar el historial de recorridos y eliminar registros según las funcionalidades disponibles.

El usuario también puede eliminar los datos de la aplicación desde la configuración de almacenamiento de Android.

### 7. Seguridad

Se aplican las medidas de seguridad proporcionadas por el sistema operativo Android y el almacenamiento interno de la aplicación para proteger la información registrada.

Sin embargo, ningún sistema de almacenamiento electrónico puede garantizar una seguridad absoluta.

### 8. Privacidad de menores

GPS Route Tracker no está diseñada específicamente para recopilar información personal de menores de edad.

La aplicación no solicita intencionalmente información personal identificable de menores.

### 9. Permisos de la aplicación

Dependiendo de las funciones habilitadas, GPS Route Tracker puede solicitar los siguientes permisos:

- **Ubicación precisa:** para obtener coordenadas GPS con mayor precisión.
- **Ubicación en segundo plano:** para continuar registrando recorridos cuando la aplicación no está en primer plano.
- **Notificaciones:** para informar al usuario sobre el estado del seguimiento, cuando corresponda.

Los permisos se utilizan exclusivamente para las funcionalidades correspondientes.

### 10. Cambios en esta política

Esta política de privacidad puede actualizarse cuando se incorporen nuevas funcionalidades o se realicen cambios en el funcionamiento de la aplicación.

Cualquier modificación será publicada en esta misma dirección web, indicando la fecha de actualización.
